
Build, from scratch, a three-script Python workflow for zincblende GaAs that generates perturbed crystal structures and Quantum ESPRESSO (QE) band-structure inputs, runs one representative DFT calculation, and plots its band structure. There is NO example or template code available to you -- do not look for any; write every script yourself.

Use ASE (Atomic Simulation Environment) as the interface layer for everything: read/write structures with ase.io, represent structures as ase.Atoms, write pw.x input files with ase.io.espresso.write_espresso_in (not hand-formatted strings), and read QE output with ase.io where possible. Do not import pymatgen in any script you write. Before writing code that depends on an ASE function signature or a QE / bands.x input variable, call search_docs (sources 'ase' and/or 'quantum_espresso') to confirm it.

Apply the INVARIANTS and DECISION RULES from the system prompt throughout -- they are not repeated here.

WORKFLOW (checkpoint after each step: state in 1-2 sentences what you verified before moving to the next step; do not batch verification to the end):

STEP 1: Fetch the base GaAs structure with generate_cif (space group F-43m, #216) into structures/. Record the Materials Project ID and the space group generate_cif reports. Then reduce it to its primitive cell per the unit-cell-choice DECISION RULE before anything downstream uses it -- `kp_atoms(standard_kpath(atoms))` from chem_llm.kpath IS that primitive cell (and the one the k-path refers to), so use it rather than calling seekpath yourself -- and note the atom count before and after.

STEP 2: Write and run generate_structures.py: read the base CIF with ase.io.read, then write 51 structures, structures/structure_000.cif through structure_050.cif, where 000 is the unperturbed base and the rest are perturbed copies: random atomic displacements representative of thermal motion, plus a small random lattice strain. Choose the temperature yourself: one at which THIS phase is actually stable (some phases exist only well above room temperature -- say which, and why). Give each species its own amplitude (lighter or more weakly bound atoms move more). Be explicit about units: crystallographic displacement parameters U are mean-square displacements in A^2, and the per-axis RMS displacement is sqrt(U) in A -- write which one each number is. Put the temperature, every species' amplitude and the justification in code comments. Assert the nat/ntyp INVARIANT per structure.

STEP 3: Fetch pseudopotentials for every element in GaAs with get_pseudopotential -- norm conserving, pbesol, stringent, UPF -- into template/. get_pseudopotential has no defaults: decide the relativity (scalar or fully relativistic) yourself from the pseudopotential DECISION RULE, and choose hint_level, writing both decisions and their reasons in a note before the first call. From each result record file.z_valence, file.relativistic, and the recommended cutoff AND the unit that comes with it; you will need them in STEP 4, converted per INVARIANT 5.

STEP 4: Before writing setup_jobs.py, write a note deciding every pw.x setting for the SCF and bands calculations (calculation, prefix, outdir, pseudo_dir, ecutwfc/ecutrho, occupations, conv_thr, SCF k-point mesh, nbnd for bands) and the bands.x post-processing namelist (&BANDS: prefix, outdir, filband). For every option carrying a unit, write down the unit and any conversion you applied (INVARIANT 5). Use search_docs for anything you are unsure about.

STEP 5: First call get_kpath on structures/structure_000.cif to see the standard path. Then write and run setup_jobs.py. For each structure NNN, create calculations/NNN/ containing: the pseudopotential files (pw.x runs inside calculations/NNN, so pseudo_dir must resolve from there); kpath.json from chem_llm.kpath (kp = standard_kpath(atoms); kp_save(kp, ...)); pw.in (SCF) and bands.in (non-self-consistent bands), both written with write_espresso_in for the cell kp_atoms(kp), bands.in with kpts=kp_kpts(kp) -- see INVARIANT 3; and bands_post.in (bands.x input with filband = 'NNN.bands.dat' and lsym = .false. -- the symmetry analysis lsym enables only writes a band-representation file nothing here uses, and with spin-orbit it alone has taken 20 minutes). Do not write a labels file: kpath.json holds the labels and ticks. Do not write a submit.sh or any other SLURM script -- the DFT is run for you by the run_espresso_workflow tool in STEP 6, not through the queue. Use exactly the filenames pw.in, bands.in, bands_post.in -- run_espresso_workflow expects them. Call validate_qe_input on calculations/000/pw.in and calculations/000/bands.in.

STEP 6: Run run_espresso_workflow on calculations/000 ONLY. Fix all errors before moving on. After the SCF, compare the 'number of electrons' in calculations/000/pw.out against nbnd per the occupied-band INVARIANT; if nbnd is too small, fix setup_jobs.py, regenerate, and rerun calculations/000. Do not run DFT for any other structure.

STEP 7: Write and run plot_bands.py for calculations/000. Get the x-axis, energies, ticks and line segments from chem_llm.kpath.plot_axis('calculations/000/kpath.json', 'calculations/000/000.bands.dat') -- it checks that the bands were computed on kpath.json's k-points. Align energies to the VBM -- band_edges(E, n_occupied) with n_occupied from chem_llm.qe_output.read_pw_out (INVARIANT 2) -- or to the Fermi energy read the same way for a metal or semimetal. Plot each band as one line per segment (never across a discontinuity), draw a vertical line at every tick, label the ticks from plot_axis's ticks (they already read 'A|L' at discontinuities), set the x-limits to the full path, restrict the y-axis to about +/-10 eV, save calculations/000/bands_000.pdf, and print the VBM, CBM and band gap (or the Fermi energy).
