    - prompt: a fixed system prompt -- agent protocol (one JSON tool call per step), numbered
      working rules, INVARIANTS the agent's scripts must assert in code (atom/species counts and
      electron count read from the actual structure and pw.out, never from memory; k-path from
      seekpath on the cell in use; unit conversions), and DECISION RULES (relativistic treatment,
      k-path source, primitive cell, plotting) -- plus a task prompt giving a 7-step workflow (fetch
      structure, perturb, pseudopotentials, decide settings, write inputs, run QE, plot) with done
      criteria. No examples or templates: the agent writes every script.
    - tools: deterministic Python functions, each returning JSON -- Materials Project fetch, Pseudo-
      Dojo fetch (reports z_valence/relativity/functional parsed from the downloaded UPF and the
      matching recommended cutoff), a k-path tool (seekpath's standard path, shared by the QE input
      and the plot), file read/write, Python execution (exit code), a QE input validator (namelists,
      nat/ntyp, k-path), a QE runner, and a documentation search (BM25 + embeddings + reranker over
      the ASE and QE docs). Facts the model is weak at come from tools, not from its memory.
    - context: each step re-prompts with the task, notes, files written, unresolved errors and the
      last 32 tool calls; trim_history on (superseded file versions, resolved failures and duplicate
      notes dropped, plus a progress ledger)
    - harness guards: a second consecutive note, a repeated doc search, or rewriting a file with
      identical content is refused; model output that is not a valid tool call is fed back as an
      error; results (gap, convergence, outputs) are re-derived from files on disk rather than
      trusted from the agent's own summary
    - QE launch command: module load espresso/7.5-libxc-7.0.0-gpu-cu13 && srun --overlap -n 4 -c 32
      --gpus-per-task=1 --gpu-bind=closest pw.x -in pw.in > pw.out 2>&1
